# 1. Gathering Training Data
The program `gather_data.py` has been implemented according to the sepcifications<br>
(It saves recorded data to `data/name-activity-num.csv`).

It asks users for their name and the activity they want to record. When prompted to do so, the recording process can be started using Button 1 on the dippid App. After the recording, users can decide to save the data, if they want to continue and update the recording options (name/activity) for following recordings.

# 2. Fitness Trainer
The fitness trainer `fitness_trainer.py` has been implemented.
At the bottom it shows you all possible actions and for how many seconds you performed them overall.
At the top it shows you what action you are currently performing and for how long.
